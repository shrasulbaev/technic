# Technic

Грузоперевозки и спецтехника для Кыргызстана: клиент предлагает свою цену,
водители откликаются или торгуются, клиент видит машину на карте. Есть
заказы «сейчас рядом» и запланированные («кто первый взял, того и заказ»),
режим «Домой» для водителя, баланс водителя с комиссией и штрафы за поздние
отмены. Пока это веб-версия (открывается с телефона), мобильные приложения
будут позже.

## Роли

- **Клиент** (`/c`): заказ грузоперевозки (точки А и Б, кузов, грузчики) или
  спецтехники (объект, часы), торг с водителями, трекинг, таймер работы
  техники, оценка.
- **Водитель** (`/d`): выход на линию, лента «Рядом», «Запланированные» по
  дням, «Мои», кнопка «Домой» (заказы по пути, крюк настраивается), баланс,
  подтверждение выезда, отказ с понятным штрафом.
- **Администратор** (`/admin`): сводка, проверка водителей, баланс, снятие
  штрафов, все заказы, клиенты, тарифы и комиссии по типам техники, правила
  штрафов.

## Что пока работает на заглушках

| Интеграция | Сейчас | Потом |
|---|---|---|
| SMS-код | код показывается на экране входа (`SMS_PROVIDER=stub`) | SMS-шлюз (например Nikita.kg) |
| Оплата баланса | пополнение проходит сразу, деньги не списываются | MBank / Элсом / O!Деньги или агрегатор |
| Карта | OpenStreetMap, адрес ставится кликом по карте или из списка мест | 2GIS: поиск адресов и маршруты |
| Маршрут | прямая линия × 1,3 | маршрут 2GIS |
| Движение машины | GPS телефона или кнопка «Тест: симулировать поездку» | GPS в приложении |
| Push | звук и обновление страницы, пока она открыта | Firebase / APNs |

С `DEMO_MODE=1` на экране входа есть кнопки демо-аккаунтов: клиент Айгерим,
водитель Портера Азамат, экскаватор Бакыт и администратор.

## Правила (меняются в админке)

- Комиссия списывается с баланса водителя в момент назначения: 8% для
  грузов и 6% для техники на старте. При минусе новые заказы не видны.
- Отмена водителем запланированного заказа: больше 24 ч — бесплатно,
  комиссия возвращается; 24–2 ч — комиссия не возвращается; меньше 2 ч,
  неподтверждённый выезд или неявка — ещё и штраф (200 сом, для техники
  50% от минималки). 3 поздние отмены за 30 дней закрывают запланированные
  заказы на 7 дней. Админ может снять штраф.
- Выезд нужно подтвердить не позже чем за 2 часа, иначе заказ сам
  возвращается в ленту со штрафом.
- Отмена клиентом возвращает водителю комиссию; поздние отмены клиента
  видны водителям.

## Разработка

Нужны Node.js 22 и Postgres 16.

```bash
cp .env.example .env
docker compose -f docker-compose.dev.yml up -d   # или свой Postgres
npm install
npm run db:migrate
npm run db:seed      # демо-данные
npm run dev
```

Проверки: `npm run check` (lint + typecheck + тесты на базе из `.env.test`)
и `npm run build`.

## Бесплатный тестовый сервер (Render)

На бесплатном Render можно держать только одну базу на аккаунт, поэтому
база живёт отдельно, в бесплатном Supabase (или Neon).

1. Supabase: проект → Connect → Session pooler, скопируйте строку
   подключения и допишите в конце `?sslmode=no-verify`.
2. На [render.com](https://render.com): New → Blueprint → репозиторий
   `technic` → вставьте строку в `DATABASE_URL` → Apply.
3. При первом старте применятся миграции и загрузятся демо-данные. Ссылка
   вида `https://technic-xxxx.onrender.com`.

Бесплатный сервер засыпает после 15 минут без запросов (первое открытие
около минуты). Бесплатный проект Supabase ставится на паузу после недели
без запросов, его включают кнопкой в панели Supabase.

## Свой сервер

`docker-compose.yml` поднимает Postgres, приложение и Caddy с HTTPS (GPS в
браузере работает только по HTTPS):

```bash
cp .env.production.example .env && nano .env
docker compose up -d --build
```
